TrustPic Privacy Policy

Last updated: May 29, 2026

TrustPic is a single-image evidence report tool. The Chrome extension lets a user right-click one image and generate an evidence report for that selected image.

Data processed

When the user chooses the TrustPic right-click action, the extension fetches the selected image and sends that image to the TrustPic API for analysis. The API returns an evidence report, including readable metadata and analysis results for that image.

Local storage

The extension stores the following data locally in Chrome:

  • the latest selected image URL;
  • the latest analysis status;
  • the latest returned evidence report;
  • the latest error message, if analysis fails;
  • the user's language preference.

This local storage is used only to display the report and remember the selected language.

Retention

TrustPic does not intentionally store uploaded original images after analysis. The extension does not save image files locally. The latest report state may remain in Chrome local storage until the user clears extension data or replaces it with another analysis.

Sharing and sale

TrustPic does not sell user data. TrustPic does not use the extension for advertising tracking, analytics SDKs, or cross-site behavioral profiling.

Website access

Host access is used only after the user right-clicks a specific image and starts analysis. The extension does not automatically scan webpages, read page content, or analyze images without user action.

Contact

For privacy questions, contact the developer through the Chrome Web Store listing or the project repository.
